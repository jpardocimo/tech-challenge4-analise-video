# =============================================================================
# NOTAS IMPORTANTES:
# =============================================================================
# 1. GPU NVIDIA (CUDA):
#    Se você tem placa de vídeo NVIDIA e quer usar aceleração:
#
#    a) Desinstale PyTorch se já instalou:
#       pip uninstall torch torchvision torchaudio
#
#    b) Instale versão CUDA:
#       pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
#
#    c) Continue com o resto do arquivo:
#       pip install -r requirements-windows.txt
#
# 2. Apenas CPU:
#    Se não tem GPU ou quer usar só CPU, apenas rode:
#       pip install -r requirements-windows.txt
#
# 3. TensorFlow GPU (opcional):
#    Se tem GPU NVIDIA e quer TensorFlow com CUDA:
#       pip uninstall tensorflow
#       pip install tensorflow[and-cuda]
#
# 4. Problemas comuns:
#    - "error: Microsoft Visual C++ 14.0 is required"
#      → Instale Visual C++ Build Tools (link acima)
#      → Marque "Desenvolvimento para Desktop com C++"
#
#    - "DLL load failed"
#      → Instale Visual C++ Redistributable (link acima)
#
#    - "No module named 'cv2'"
#      → pip install --upgrade opencv-python
#
#    - "tf_keras" não encontrado com tensorflow>=2.20
#      → pip install tf-keras
#
# 5. Versões do Python:
#    - Recomendado: Python 3.10 ou 3.11
#    - Evite: Python 3.12+ (algumas libs ainda não têm suporte completo)
#
# 6. Desempenho esperado:
#    - CPU: ~5-10 FPS no processamento
#    - GPU NVIDIA (CUDA): ~30-60 FPS
#
# 7. Modelos do InsightFace:
#    - São baixados automaticamente na primeira execução
#    - Local: ~/.insightface/models/buffalo_l/
#    - Tamanho: ~600MB
# =============================================================================
